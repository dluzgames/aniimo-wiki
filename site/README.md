# Aniimo Wiki Copy

Réplica local estática da interface pública de `wiki.aniimo.com`, criada para estudo e uso local.

## Executar

Abra `index.html` diretamente no navegador ou sirva a pasta com qualquer servidor estático, por exemplo:

```powershell
python -m http.server 4173 --directory H:\ollama\aniimo-wiki-copy
```

A cópia inclui 94 criaturas, busca, filtros, ordenação, navegação para detalhes e os principais assets visuais baixados localmente.
